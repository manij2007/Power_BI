## 📌 Project Overview

**COVID-19 Dataset Analytics** is a Business Intelligence project developed using Microsoft Power BI to explore and visualize the global impact of the COVID-19 pandemic.

The dashboard provides an overview of confirmed cases, new cases, and total deaths, helping users understand how the pandemic has affected different regions around the world.

Through interactive visualizations and geographical comparisons, this project transforms COVID-19 data into meaningful insights.

## 🎯 Project Objectives

- Analyze the global distribution of COVID-19 cases.
- Explore total and newly reported cases.
- Examine COVID-19 deaths across different continents.
- Compare the impact of the pandemic across countries.
- Identify regions with higher reported death counts.
- Present complex health-related data through clear visualizations.

## 📊 Dashboard Features

The dashboard includes several visual components designed to provide a comprehensive overview of COVID-19 statistics.

### 1. Key Performance Indicators (KPIs)

KPI cards highlight important pandemic statistics:

- **Total Deaths** – Overall reported COVID-19 deaths.
- **Total Cases** – Total reported COVID-19 cases.
- **New Cases** – Newly reported COVID-19 cases.

### 2. COVID-19 Cases by Continent

A pie chart illustrates the distribution of total reported cases across different continents.

This visualization helps compare the relative share of reported cases in each region.

### 3. COVID-19 Deaths by Continent

A second pie chart presents the distribution of total deaths across continents, providing a geographical perspective on the pandemic's reported impact.

### 4. Deaths by Country

A treemap visualizes total reported deaths across individual countries.

This allows users to identify countries with larger reported death counts and compare their relative contributions.

### 5. Country-Level Data Table

A detailed table provides country-level information, including:

- Continent
- Country
- Total Deaths

The table is sorted by total deaths in descending order to make comparisons easier.

## 🔍 Key Analytical Questions

This project helps investigate several important questions:

- Which continents account for the largest share of reported COVID-19 cases?
- How are reported deaths distributed across continents?
- Which countries have the highest reported death counts?
- What is the relationship between total cases and total deaths?
- How does the global distribution of the pandemic vary across regions?

## 🚀 Getting Started

To explore the dashboard:

1. Clone or download this repository.
2. Install [Microsoft Power BI Desktop](https://powerbi.microsoft.com/desktop/).
3. Open `Covid19_Dataset_Analytics.pbix`.
4. Explore the dashboard and its visualizations.

## 💡 Project Purpose

This project demonstrates how Business Intelligence tools can be used to transform large-scale public health datasets into understandable visual insights.

By leveraging Microsoft Power BI, it provides a practical example of data analysis, geographical comparison, KPI monitoring, and interactive dashboard development.

**Note:** COVID-19 statistics depend on the underlying dataset, reporting practices, and reporting period. The dashboard presents reported figures rather than independently verified estimates.
