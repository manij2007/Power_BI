## 📌 Project Overview

**Olympics Dataset Analytics** is a Business Intelligence project developed using Microsoft Power BI. The main goal is to explore Olympic data and gain a better understanding of medal distributions across countries, sports, seasons, and athlete demographics.

The dashboard transforms Olympic data into interactive visualizations, making it easier to identify patterns, compare performance, and explore different aspects of Olympic competitions.

## 🎯 Project Objectives

- Analyze Olympic medal distributions across different countries.
- Compare medal counts between Olympic seasons.
- Explore medal distribution across different sports.
- Investigate medal statistics based on gender.
- Analyze medal counts associated with individual athletes.
- Explore the relationship between athletes' age and medal distribution.

## 📊 Dashboard Features

The project consists of two interactive report pages, each focusing on different aspects of Olympic data.

### 1. Olympic Performance Overview

This page provides a general overview of Olympic medal statistics through several visualizations.

**Key Visualizations:**

- **Season & Country Analysis:** A column chart comparing medal counts across Olympic seasons and countries.
- **Medals by Sport:** A treemap illustrating how medals are distributed across different sports.
- **KPI Cards:** Summary cards displaying key medal-related metrics.

### 2. Athlete & Medal Analysis

This page focuses on athlete demographics and medal distribution.

**Key Visualizations:**

- **Medals by Gender:** A pie chart showing the distribution of medals between male and female athletes.
- **Medals by Athlete:** A column chart comparing medal counts associated with individual athletes.
- **Age-Based Medal Analysis:** A ribbon chart exploring medal distribution across different age groups.

## 🚀 Getting Started

To explore the dashboard:

1. Clone or download this repository.
2. Install [Microsoft Power BI Desktop](https://powerbi.microsoft.com/desktop/).
3. Open `Olympics_Dataset_Analytics.pbix`.
4. Navigate through the report pages.
5. Interact with the charts and explore Olympic data from different perspectives.

This project demonstrates how Business Intelligence and data visualization techniques can be applied to sports analytics.
